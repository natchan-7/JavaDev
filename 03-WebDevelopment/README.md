# Spring Boot Web開発

## 学習目標
- Webアプリケーションの基本を理解
- REST APIの設計・実装
- データベース連携
- セキュリティ対策

## 技術スタック
- **Framework**: Spring Boot
- **Template**: Thymeleaf
- **Database**: H2 (開発用) → PostgreSQL (本番)
- **Security**: Spring Security
