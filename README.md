# Java個人開発プロジェクト

## 環境構成
- **JDK**: OpenJDK 21.0.8
- **IDE**: IntelliJ IDEA
- **ビルドツール**: Maven/Gradle
- **バージョン管理**: Git
- **AI支援**: Claude Code
- **開発OS**: Windows

## 学習ロードマップ
1. **01-Basics**: Java基礎文法
2. **02-ObjectOriented**: オブジェクト指向プログラミング
3. **03-WebDevelopment**: Spring Boot Webアプリケーション
4. **04-Practice**: 実践プロジェクト
5. **05-Portfolio**: ポートフォリオ作品

## Claude Code活用法
`ash
# プロジェクトディレクトリに移動
cd C:\JavaDev\01-Basics

# Claude Codeでコードレビュー
claude review MyClass.java

# 練習問題生成
claude "Create a Java exercise for beginners about variables"
`

## 開発フロー
1. Claude Codeで課題生成
2. IntelliJ IDEAで実装
3. ローカルテスト実行
4. Gitでバージョン管理
5. Claude Codeでコードレビュー
